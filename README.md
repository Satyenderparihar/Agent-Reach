## ❓ Agent Reach की आवश्यकता क्यों है?

AI Agent आपके लिए कोड लिख सकते हैं, डॉक्यूमेंट्स सुधार सकते हैं और प्रोजेक्ट्स मैनेज कर सकते हैं — लेकिन जब आप उन्हें इंटरनेट पर लाइव सोशल डेटा या कम्युनिटी चर्चाएँ खोजने को कहते हैं, तो वे अटक जाते हैं।

इंटरनेट पर सबसे मूल्यवान और ताज़ा जानकारी सोशल मीडिया और टेक कम्युनिटीज़ में होती है: **Twitter चर्चाएँ, Reddit फ़ीडबैक, YouTube ट्यूटोरियल्स, GitHub एक्टिविटी और ब्लॉग्स**। यह वह जगह है जहाँ जानकारी का घनत्व (Information Density) सबसे अधिक होता है, लेकिन हर प्लेटफ़ॉर्म की अपनी बाधाएँ हैं:

| प्लेटफ़ॉर्म की समस्या | ज़मीनी हकीकत |
|---|---|
| **Twitter API** | प्रति उपयोग शुल्क (Pay-per-use), सामान्य उपयोग पर लगभग ~$215/माह का खर्च |
| **Reddit** | सर्वर IPs को 403 Forbidden एरर देकर ब्लॉक कर दिया जाता है |
| **YouTube & Video Sites** | बिना API के सबटाइटल्स और ट्रांसक्रिप्ट्स निकालना मुश्किल होता है |
| **वेब पेज स्क्रैपिंग** | विज्ञापनों और जावास्क्रिप्ट के कारण कचरा HTML मिलता है |

अपने AI Agent को इन सभी प्लेटफ़ॉर्म्स से कनेक्ट करने के लिए आपको अलग-अलग टूल्स खोजने, डिपेंडेंसीज़ इंस्टॉल करने और कॉन्फ़िगरेशन डिबग करने में घंटों बिताने पड़ते हैं।

**Agent Reach इसे सिर्फ एक कमांड में बदल देता है:**
अब आपका AI Agent बिना किसी API फीस के सीधे Twitter पढ़ सकता है, Reddit सर्च कर सकता है और YouTube वीडियोज़ का विश्लेषण कर सकता है।

## ✅ मुख्य विशेषताएं (Key Highlights)

- 💰 **100% मुफ़्त (Completely Free)**: सभी टूल्स ओपन-सोर्स हैं और सभी एक्सेस पाथ मुफ़्त हैं। कोई महँगी API सब्सक्रिप्शन लेने की आवश्यकता नहीं है।
- 🔒 **प्राइवेसी और सुरक्षा (Privacy Safe)**: आपकी Cookies और टोकन्स केवल आपकी लोकल मशीन पर सुरक्षित रहते हैं। कोई डेटा क्लाउड पर अपलोड नहीं होता।
- 🔄 **ऑटो-फेलओवर और अपडेट्स (Auto-Fallback)**: प्रत्येक प्लेटफ़ॉर्म के लिए प्राइमरी और सेकेंडरी बैकएंड सूची होती है। यदि कोई रास्ता ब्लॉक होता है, तो यह बिना आपके हस्तक्षेप के स्वतः दूसरे रास्ते पर स्विच कर जाता है।
- 🤖 **हर AI Agent के साथ संगत (Universal Compatibility)**: Antigravity, Claude Code, OpenClaw, Cursor, Windsurf — किसी भी ऐसे AI Agent के साथ काम करता है जो टर्मिनल कमांड्स चला सकता है।
- 🩺 **अंतर्निहित हेल्थ-चेक (Built-in Diagnostics)**: `agent-reach doctor` चलाकर आप एक नज़र में देख सकते हैं कि कौन सा प्लेटफ़ॉर्म रेडी है और किसे फिक्स करने की ज़रूरत है।

## 🌐 समर्थित प्लेटफ़ॉर्म (Supported Platforms)

| प्लेटफ़ॉर्म | क्षमताएँ (Capabilities) | सेटअप का स्तर | विवरण |
|---|---|:---:|---|
| 🌐 **Web Pages** | Read (पढ़ना) | Zero Config | किसी भी URL को साफ़ और स्ट्रक्चर्ड Markdown में बदलता है ([Jina Reader](https://github.com/jina-ai/reader) द्वारा संचालित)। |
| 📦 **GitHub** | Read · Search | Zero Config | [gh CLI](https://cli.github.com) द्वारा संचालित। पब्लिक रिपॉजिटरीज़ तुरंत काम करती हैं। `gh auth login` से इश्यूज और PRs अनलॉक होते हैं। |
| 📺 **YouTube** | Read · Search | Zero Config | 1800+ वीडियो वेबसाइट्स से सबटाइटल्स, ट्रांसक्रिप्ट्स और मेटाडेटा एक्सट्रैक्ट करता है ([yt-dlp](https://github.com/yt-dlp/yt-dlp) द्वारा)। |
| 🐦 **Twitter/X** | Read · Search | Cookie आधारित | बिना किसी पेड API के ट्वीट्स पढ़ना, सर्च करना और प्रोफ़ाइल टाइमलाइन देखना ([twitter-cli](https://github.com/public-clis/twitter-cli) द्वारा)। |
| 📖 **Reddit** | Search · Read | Cookie / CLI | सब-रेडिट्स और कम्युनिटी पोस्ट्स को बिना ब्लॉक हुए सीधे सर्च और रीड करना ([rdt-cli](https://github.com/public-clis/rdt-cli) द्वारा)। |
| 📡 **RSS Feeds** | Read | Zero Config | किसी भी RSS या Atom न्यूज़ फ़ीड को साफ़ टेक्स्ट में पार्स करना ([feedparser](https://github.com/kurtmckee/feedparser) द्वारा)। |
| 🔍 **Web Search** | Live Search | Auto Config | फ्री लाइव वेब सर्च बिना किसी API Key के ([Exa](https://exa.ai) / mcporter द्वारा)। |

## 🚀 त्वरित शुरुआत (Quick Start)

### 1. इंस्टॉलेशन (Installation):

```bash
# Python पैकेज इंस्टॉल करें
pip install -e .

# ऑटोमैटिक एनवायरनमेंट सेटअप रन करें
agent-reach install --env=auto
```

### 2. हेल्थ-चेक डायग्नोस्टिक्स (Doctor Check):

सिस्टम और सभी सोशल प्लेटफ़ॉर्म्स की लाइव कनेक्टिविटी चेक करने के लिए:

```bash
agent-reach doctor
```

यह कमांड एक सुंदर रंगीन डैशबोर्ड में दिखाएगी कि कौन से टूल्स तैयार हैं और कौन से वैकल्पिक टूल्स को Cookie या सेटअप की आवश्यकता है।

## ⚡ यह बिना किसी कमांड याद रखे तुरंत काम करता है!

आपको कोई कठिन कमांड याद रखने की ज़रूरत नहीं है। बस अपने AI Agent से सामान्य भाषा में कहें:

- *"इस लिंक का सारांश बताओ"* ➔ `curl https://r.jina.ai/URL` द्वारा साफ़ Markdown पढ़ेगा।
- *"इस GitHub repo में क्या है?"* ➔ `gh repo view owner/repo` से जानकारी निकालेगा।
- *"इस YouTube वीडियो में क्या सिखाया गया है?"* ➔ `yt-dlp` से सबटाइटल्स डाउनलोड करके समझ लेगा।
- *"Twitter पर AI Agents के बारे में क्या ट्रेंड चल रहा है?"* ➔ `twitter search "AI agents"` से ट्वीट्स पढ़ेगा।
- *"Reddit पर इस बग का क्या सॉल्यूशन दिया गया है?"* ➔ Reddit थ्रेड्स को बिना ब्लॉक हुए पढ़ेगा।
